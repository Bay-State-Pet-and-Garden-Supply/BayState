# Design System: Heritage & Trust

## Color Strategy: Restrained
- **Primary Brand:** Deep Forest Green (`oklch(35% 0.08 160)`).
- **Backgrounds:** Warm, creamy off-white (`oklch(98% 0.01 90)`). Never pure `#fff`.
- **Text/Foreground:** Deep warm gray (`oklch(25% 0.02 90)`). Never pure `#000`.
- **Borders:** Subtle 1px strokes tinted toward the brand green (`oklch(85% 0.03 160)`).

## Typography
- **Headings (Brand):** Serif (e.g., Playfair Display or Merriweather). Used in storefront for h1-h3.
- **UI/Body (Product):** Sans-serif (e.g., Inter). Used for all body text, admin panel headings, and data tables.

## Elevation & Components
- **Shadows:** Soft, realistic, multi-layered drop shadows. No solid offset blocks.
- **Buttons:** Subtle inner shadows or minimal gradients to invite interaction.
- **Cards:** Simple 1px borders with warm backgrounds, avoiding heavy repetitive grids.
