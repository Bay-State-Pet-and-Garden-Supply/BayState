### Part 2: Minimal server-authoritative pricing
- **Created `lib/pricing/verify-cart.ts`**: Server-only module that fetches product/service prices from DB, rejects client-provided prices, handles service items, computes delivery fee/tax/total. Supports pickup and delivery flows.

- **Modified `lib/orders.ts`**: `createOrderWithClient()` accepts `verifiedCart` parameter. Uses verified totals when available (subtotal, discount, delivery fee, tax). Builds order_items from verified item data.
- **Modified `components/storefront/checkout/checkout-client.tsx`**: Sends only safe `{id, quantity}` for items. Removes `discountAmount`, `deliveryFee`, `deliveryDistanceMiles`, `paymentStatus` from payload. Keeps visual UI estimates for display only.
- **Added tests**: 8 verifyCart unit tests covering DB price verification, missing product rejection, service items, pickup/delivery fee, tax computation, total computation.
