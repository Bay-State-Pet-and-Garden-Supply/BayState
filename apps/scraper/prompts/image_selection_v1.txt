# Image Selection Prompt v1

You are a precise data extraction agent. Your job is to select the correct product images for a product detail page (PDP).

EXPECTED PRODUCT DETAILS:
- Name: {product_name}
- Brand: {brand}
- Expected Flavor/Protein/Attributes: {expected_flavor_tokens}

We have already crawled the web page and extracted several candidate images. Below is the list of unique candidate images:

CANDIDATES:
{candidates_json}

INSTRUCTIONS:
Classify each image into one of three roles:
1. "primary": The main product packaging or product image showing the exact item described by the expected product details. There must be at most one primary image.
2. "gallery": An additional product image showing other angles, back label, ingredients lists, or close-ups of the exact same product.
3. "rejected": A non-product image, brand logo, social media icon, general banner, trust badge, shipping icon, or an image of a completely different/related product (e.g., cross-sells, recommended products, different flavors/variants).

CRITICAL POLICIES:
- Cross-Flavor/Variant Detection: Reject images that belong to a different flavor, size, variant, or product (e.g., if expected flavor is "Chicken" and the candidate image filename/alt is "beef-treats.jpg", reject it).
- Reject UI Assets: Reject logos, icons, trust badges, payment methods, stars, and placeholders.
- Focus on the expected product name and brand. If the product name indicates "Pumpkin Cheesecake", do not match images for "Peanut Butter".
- If no candidate image is a good match for the product, classify all of them as "rejected".

OUTPUT FORMAT:
You MUST return a JSON object with a single key "selected_images" which is an array of objects.
Do not return any text other than the JSON object.
JSON Schema:
{{
  "selected_images": [
    {{
      "index": int,
      "role": "primary" | "gallery" | "rejected",
      "reason": "Short explanation of the classification"
    }}
  ]
}}
